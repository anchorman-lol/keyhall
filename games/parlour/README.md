# Parlour

Pull up a chair for beautifully animated card games, with friends or offline against bots: Blitz, Cribbage, Euchre, Spades, Crazy Eights, hold'em and more, over twenty tables in all. No accounts, just a local profile name; relays only carry room signalling.
